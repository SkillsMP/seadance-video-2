## 1. 四个站各学什么

### A. banana2ai：学“工程实现”

这个是你的**代码样板间**。

重点学：

```txt
/api/ai/generate
/api/ai/query
/api/ai/notify/[provider]
ImageGenerator
VideoGeneratorPanel
PricingModal
ModelDetailPage
image-tools.ts
video-tools.ts
R2 转存
credits 扣费
任务状态轮询
```

它解决的是：**ShipAny 怎么真正变成 AI 图片/视频工具站。**

---

### B. gptimg2.art：学“页面叙事”和“工作流包装”

gptimg2.art 首页不是简单说 “GPT Image 2 generator”，而是把 GPT Image 2 包装成能做 **真实图片、UI 截图、产品 mockup、可编辑视觉概念** 的工具，而且强调 prompt following、图中文字、快速迭代。([gptimg2art][1])

更值得学的是它的 `/models/gpt-image-2` 页面。这个页面的核心不是“模型介绍”，而是：

```txt
先生成第一张高质量图
再把图变成视频资产
```

它把 GPT Image 2 定位成视频前置资产生产器：storyboard、character sheet、product hero、app UI screens，然后再进入 image-to-video workflow。页面里明确写了 storyboard to video、character sheet to animation、app UI to demo video、product visual to short ad 这些工作流。([gptimg2art][2])

你应该学它这套：

```txt
Image model 不只是生成图
而是 Video workflow 的前置资产生产器
```

这对你非常重要。因为你以后可以把页面写成：

```txt
GPT Image 2 for Video Ads
Nano Banana Pro for Product Video Assets
Seedance 2.0 Workflow from Image to Video
AI Storyboard Generator
AI Product Hero Shot to Video
```

这比单纯做 “AI Image Generator” 高一个维度。

---

### C. tool.video：学“视频工具矩阵”和“API/MCP 形态”

tool.video 首页定位很清楚：**All-in-one Video Toolkit**，工具组合包括 Sora 2、Nano Banana Pro、thumbnail generation、AI music 等。首页还把流程写成 storyboard → video creation → background music → thumbnail。([Tool Video][3])

它最值得学的是两个东西。

第一，它不是只做 AI Video Generator，而是做一整套视频工具矩阵：

```txt
AI Video Generator
AI Image Generator
AI Music Generator
AI TVC Generator
Video Thumbnail Generator
Video Watermark Adder
Video Trimmer
Sora Watermark Remover
```

这些都出现在它首页和 footer 工具入口里。([Tool Video][3])

第二，它每个工具页都带 **Playground / API / MCP** 这种开发者包装。比如 AI TVC Generator 页面里有 Playground、API、MCP，并且表单包含广告主题、参考图、voiceover script、30 credits、视频预览、gallery。([Tool Video][4])

这个很适合你学：

```txt
普通用户看到 Playground
开发者看到 API
高级用户看到 MCP
SEO 用户看到完整工具页
```

你未来可以给每个工具页加三个 tab：

```txt
Playground
API
Workflow
```

暂时 MCP 不一定真做，但页面表达可以先有。

---

### D. nanobanana.im：学“LoRA/风格页矩阵”和“长尾入口”

nanobanana.im 首页已经不是单一工具页，而是 **Nano Banana AI Image & Video Platform**，导航里包含 Nano Banana、Nano Banana Pro、Nano Banana 2、GPT Image 2、Prompts、Pricing、My Images。页面首屏直接放生成器，下面是 use cases、before/after、why choose、how it works、FAQ。([Nano Banana][5])

它最强的是 footer 和 LoRA 矩阵。首页 footer 里挂了大量 LoRA/风格入口，例如 Y2K Style AI、Scream AI Picture、Image To Pixel、AI Bald Filter、LinkedIn Photo Generator、Old Photo Restore、Candy Cane AI、YouTube Thumbnail Generator、Watermark Remover、Image Restoration 等。([Nano Banana][5])

它的 `/nano-banana-lora` 页面更明显，是一个风格/滤镜/效果库，每个卡片有 before/after 图、标题、描述、标签和 “Try it out”。比如 Engraving Portrait、Pet to Human、Hair Color Filter、Grey Hair Filter、AI Professional Headshot 等。([Nano Banana][6])

你应该学它这个结构：

```txt
一个模型
    ↓
拆成几十个 LoRA / Style / Effect / Filter 页面
    ↓
每页一个 before/after
    ↓
一键 Try it out
```

这非常适合做 SEO 长尾。

## 2. 你应该怎么融合这四个站

不要做成“四不像”。你应该给它们分角色：

| 来源            | 学习重点      | 迁移到你项目里的形态                               |
| ------------- | --------- | ---------------------------------------- |
| banana2ai     | 代码和生成闭环   | 后端 API、credits、R2、generator              |
| gptimg2.art   | 工作流叙事     | GPT Image 2 / 图生视频前置资产页                  |
| tool.video    | 视频工具矩阵    | `/video-tools/`、API tab、TVC/thumbnail 工具 |
| nanobanana.im | LoRA 长尾矩阵 | `/lora/`、风格页、before/after gallery        |

你的最终模板应该长这样：

```txt
主站首页
  ↓
/image/                 图片生成主入口
/video/                 视频生成主入口
/models/[slug]          模型页
/tools/[slug]           工具页
/lora/[slug]            风格/滤镜页
/prompts/[slug]         Prompt 页
/workflows/[slug]       工作流页
/api-tools/[slug]       API/MCP 包装页
/pricing                定价页
```

## 3. 你现在最该先做哪个

我建议优先级是：

```txt
P0：banana2ai 生成闭环
P1：gptimg2.art 的 workflow 页面结构
P2：nanobanana.im 的 LoRA/风格矩阵
P3：tool.video 的视频工具矩阵和 API/MCP 包装
```

原因很简单：

**没有生成闭环，页面再多也只是空壳。**
所以先用 banana2ai 把核心功能跑通。

然后用 gptimg2.art 的方法，把你的页面写得更像“真实创作工作流”，不是模型说明书。

再用 nanobanana.im 的方法，批量做风格页。

最后用 tool.video 的方法，把视频工具和 API 包装起来。

## 5. 具体抄法

### 从 gptimg2.art 抄

抄它的 **workflow 叙事**：

```txt
先生成稳定图片资产
再进入视频
```

你可以做这些页面：

```txt
/workflows/storyboard-to-video
/workflows/character-sheet-to-animation
/workflows/product-visual-to-short-ad
/workflows/app-ui-to-demo-video
/image/gpt-image-2
/image/nano-banana-pro-for-video
```

gptimg2.art 的模型页已经把 storyboards、character sheets、campaign visuals、product hero、UI screens 这些做成模板入口，这个结构非常值得复制。([gptimg2art][2])

---

### 从 tool.video 抄

抄它的 **工具矩阵 + API 包装**：

```txt
/video/ai-video-generator
/video/sora-2
/video/ai-tvc-generator
/video/video-thumbnail-generator
/video/video-trimmer
/video/video-watermark-adder
/video/ai-video-thumbnail-generator
```

尤其 Video Thumbnail Generator 很值得你做，因为它不是纯 AI 热词，而是刚需工具。页面里它强调：用 thumbnail 替代直接加载重视频，可以提升加载速度、SEO/Core Web Vitals、降低带宽成本。([Tool Video][7])

这种工具词通常比纯模型词更稳定。

---

### 从 nanobanana.im 抄

抄它的 **LoRA/效果页矩阵**：

```txt
/lora/ai-headshot
/lora/hair-color-filter
/lora/grey-hair-filter
/lora/pet-to-human
/lora/engraving-portrait
/lora/youtube-thumbnail-generator
/lora/old-photo-restore
/lora/watermark-remover
/lora/image-to-pixel
```

每个页面都用统一模板：

```txt
H1
一句话说明效果
上传区 / Try it out
before/after carousel
prompt preset
use cases
FAQ
related LoRAs
```

nanobanana.im 的 LoRA 页就是这种逻辑：卡片化 before/after、标签、Try it out，非常适合规模化。([Nano Banana][6])

## 6. 最终你应该做的不是一个站，而是一个“AI 视觉站模板”

你的目标不是只做 bananapro.org，而是沉淀一套：

```txt
AI Image + AI Video + Prompt + LoRA + Workflow + API
```

模板内部数据结构可以这样设计：

```txt
src/data/
  models.ts
  imageTools.ts
  videoTools.ts
  loraPresets.ts
  promptTemplates.ts
  workflowTemplates.ts
  apiTools.ts
```

页面路由：

```txt
/image/[slug]
/video/[slug]
/tools/[slug]
/lora/[slug]
/prompts/[slug]
/workflows/[slug]
```

组件：

