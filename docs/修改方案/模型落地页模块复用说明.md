# 模型落地页模块复用说明

Seedance 2.0 为首个样板。保留现有动态页面与生成器注入方式，不需要新的页面框架。

## 复制模型页

1. 按样板语言 JSON 的顺序组织 Hero、Generator、Examples、Features、Specifications、Use Cases、How To、FAQ、Related Resources、CTA。
2. 替换模型文案和真实素材。没有可核实案例时设置 `examples.disabled: true`，保留空 `items`；调用 `prepareModelLandingPage` 同步移除案例链接。
3. 规格模块指定 `block: "model-specs"`、`mediaType`、明确的 `modelFamilies`，需要限定工作流时增加 `scenes`。复制样板的 labels、`inputItems`、`limitsItems` 后按语言调整，数值不用填入 JSON。
4. FAQ 写短答案，数字指向规格表，不把配置展开进句子。页面展示与 JSON-LD 使用同一份 `faq.items`。
5. `related-resources` 使用 `items` 的 `title`、`description`、`url`；How To 用 `features-step` 并设 `columns: 3`；`features` 的 `columns: 4` 只在需要四列时设置，原有页面默认三列。

## 展示与边界

- `model-specs` 在服务端读取模型注册表及原计费函数，不修改模型配置与扣费逻辑。按型号汇总成一行：同价工作流合并，视频转视频等例外写在同一格。
- `inputItems` 与 `limitsItems` 用于经核实的输入说明和限制，不能补写未知能力。
- 本页 `hero.compact: true` 压缩首屏留白；FAQ 配置 `block: "model-faq"`，使用独立的服务端原生折叠问答，答案包含在 HTML 中。原有 FAQ 组件及旧页面的交互不变。
- 生成器当前继续展示全站已启用的视频模型，模型页专属筛选属于后续工作。
- 现有素材不能核实型号，样板暂时隐藏 Examples。后续填入确认属于本页模型的素材并启用即可。
- 首页、Image to Video 等功能页可以复用 Block，但分别决定内容顺序和重点，不直接照搬整页文案。

验证：`pnpm exec tsx scripts/test-model-landing.ts`。上线前再检查 HTML 中的标题、规格表、FAQ、内链，以及桌面和手机布局。
