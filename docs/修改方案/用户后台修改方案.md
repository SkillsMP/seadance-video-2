## 文件 1：`src/app/[locale]/(landing)/activity/ai-tasks/page.tsx`

### 1）在 imports 下面加一个很轻的下载链接组件

放在 `export default async function AiTasksPage` 前面：

```tsx
function DownloadLink({ href, title }: { href: string; title: string }) {
  const isRemote = /^https?:\/\//.test(href);
  const downloadHref = isRemote
    ? `/api/proxy/file?url=${encodeURIComponent(href)}`
    : href;

  let filename = '';
  try {
    const url = new URL(href, 'http://x');
    filename = decodeURIComponent(url.pathname.split('/').pop() || '');
  } catch {
    // ignore invalid href
  }

  return (
    <a
      href={downloadHref}
      download={filename || true}
      className="text-primary text-sm font-medium hover:underline"
    >
      {title}
    </a>
  );
}
```

这里不要直接 `href={href}` 下载远程文件：跨域 URL 下浏览器经常会忽略 `download`，变成打开新标签预览。项目里已经有 `/api/proxy/file`，这里只把 `http/https` URL 走现有代理，不新增下载代理 API。

同时给 `<a download>` 显式塞文件名，避免代理 URL `/api/proxy/file?url=...` 下载出来变成没有扩展名的 `file`。不要去改 `/api/proxy/file` 的 `Content-Disposition`：这个代理可能被预览和下载场景复用，后端强制 `attachment` 有回归风险。

这个组件足够了，不建议加 `getDownloadUrls`、`parseTaskInfo`、`getDownloadTitle` 这些辅助函数。先保持收敛。

### 2）表格列调整

把现在这几列：

```tsx
{ name: 'prompt', title: t('fields.prompt'), type: 'copy' },
{ name: 'mediaType', title: t('fields.media_type'), type: 'label' },
{ name: 'provider', title: t('fields.provider'), type: 'label' },
{ name: 'model', title: t('fields.model'), type: 'label' },
```

改成：

```tsx
{
  name: 'prompt',
  title: t('fields.prompt'),
  type: 'copy',
  className: 'min-w-64 max-w-[360px] whitespace-normal break-words',
},
{ name: 'mediaType', title: t('fields.media_type'), type: 'label' },
{ name: 'model', title: t('fields.model'), type: 'label' },
```

核心是：**删除 Provider**，Prompt 加宽度和换行。

注意：`td` 的 `max-width` 在默认 `table-layout: auto` 下不一定完全严格。先按这个改，然后用 200+ 字符的 Prompt 实测；如果仍然撑开，只在这一列追加 `w-[360px]`，不要改通用 `Table`。

### 4）图片结果下方加下载

把原来的图片分支：

```tsx
} else if (taskInfo.images && taskInfo.images.length > 0) {
  return (
    <div className="flex flex-col gap-2">
      {taskInfo.images.map((image: any, index: number) => (
        <LazyImage
          key={index}
          src={image.imageUrl}
          alt="Generated image"
          className="h-32 w-auto"
        />
      ))}
    </div>
  );
}
```

改成：

```tsx
} else if (taskInfo.images && taskInfo.images.length > 0) {
  const images: any[] = taskInfo.images.filter(
    (image: any) => image.imageUrl
  );

  if (images.length > 0) {
    return (
      <div className="flex flex-col gap-3">
        {images.map((image: any, index: number) => (
          <div key={index} className="flex flex-col gap-2">
            <LazyImage
              src={image.imageUrl}
              alt="Generated image"
              className="h-auto max-h-32 w-auto max-w-[240px] object-contain"
            />
            <DownloadLink
              href={image.imageUrl}
              title={t('list.buttons.download')}
            />
          </div>
        ))}
      </div>
    );
  }
}
```

图片类型里 `imageUrl` 是可选字段，先过滤可以避免给 `LazyImage` 传空地址。外层用 `gap-3` 拉开多张图片之间的距离，单张图片内部仍保持 `gap-2`。

这里不要继续用 `h-32 w-auto`：表格列宽被压缩时，图片宽度会被浏览器限制，但高度仍固定为 `h-32`，容易横向挤压变形。改成 `h-auto max-h-32 w-auto max-w-[240px] object-contain` 后，图片按原始比例缩放，最多占用 128px 高、240px 宽，不需要改通用 `Table` 或 `LazyImage`。
