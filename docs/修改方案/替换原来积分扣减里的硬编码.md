# 替换原来积分扣减里的硬编码

## 0. 重新审核结论

这个方案可以做，属于优雅且保守的最小抽象。

关键判断：

- 值得抽，因为当前已经有后端真实扣费、图片前端显示、视频前端显示 3 份硬编码。
- 只抽一个纯函数 helper，不引入配置中心、策略引擎、数据库配置或支付套餐耦合。
- 第一版必须保持旧扣费行为不变，只把规则改成单一来源。
- 新增文件可以放在 `src/config/ai/credit-costs.ts`，但不要从 `src/config/index.ts` 统一导出，前端组件必须直接 import 子路径。
- `src/config/ai` 目录当前不存在，可以新建；不要顺手改现有 config 聚合结构。

最终边界：

```text
新增 1 个纯函数文件。
修改 3 个调用点。
不改数据库、支付、任务模型、积分账本。
```

## 1. 目标

把当前分散在 3 个地方的积分扣费硬编码，收敛到一个非常薄的 helper：

```text
src/config/ai/credit-costs.ts
```

第一版只做一件事：

```text
保持当前扣费行为不变，消除重复硬编码。
```

不做这些事：

- 不改数据库
- 不改 `credit` 扣减链路
- 不改 `ai_task` 任务模型
- 不改支付套餐
- 不改 pricing 页面配置
- 不做后台管理配置
- 不做远程配置
- 不做策略引擎
- 不把供应商成本、毛利、安全线写进代码

---

## 2. 当前问题

现在积分扣费规则分散在 3 个文件里。

| 位置 | 文件 | 当前硬编码 |
|---|---|---|
| 后端真实扣费 | `src/app/api/ai/generate/route.ts` | image `4 / 6`，video `6 / 8 / 10`，music `10` |
| 图片前端显示 | `src/shared/blocks/generator/image.tsx` | `useState(4)`，tab 切换时 `setCostCredits(4 / 6)` |
| 视频前端显示 | `src/shared/blocks/generator/video.tsx` | `textToVideoCredits = 6`，`imageToVideoCredits = 8`，`videoToVideoCredits = 10` |

风险：

- 前端显示和后端真实扣费可能不一致。
- 后续模型级扣费上线时，需要同时找多个文件改。
- Pricing 页面说法、生成器显示、真实扣费容易分叉。

---

## 3. 推荐方案

新增一个纯函数文件：

```text
src/config/ai/credit-costs.ts
```

职责只包含：

```text
输入：mediaType / scene / family / model
输出：本次生成应扣多少 credits
```

它不负责：

- 不负责创建任务
- 不负责扣数据库积分
- 不负责退款
- 不负责支付套餐
- 不负责 pricing SKU
- 不负责供应商 fallback
- 不负责毛利计算

## 4. 新增文件设计

新增：

```ts
// src/config/ai/credit-costs.ts

export type GenerationMediaType = 'image' | 'video' | 'music';

export type GenerationScene =
  | 'text-to-image'
  | 'image-to-image'
  | 'text-to-video'
  | 'image-to-video'
  | 'video-to-video'
  | 'text-to-music';

export interface GenerationCreditCostInput {
  mediaType: GenerationMediaType | string;
  scene?: GenerationScene | string;
  family?: string;
  model?: string;
}

const DEFAULT_SCENE_CREDIT_COSTS: Record<
  string,
  Partial<Record<string, number>>
> = {
  image: {
    'text-to-image': 4,
    'image-to-image': 6,
  },
  video: {
    'text-to-video': 6,
    'image-to-video': 8,
    'video-to-video': 10,
  },
  music: {
    'text-to-music': 10,
  },
};

export function getGenerationCreditCost({
  mediaType,
  scene,
}: GenerationCreditCostInput): number {
  const mediaCosts = DEFAULT_SCENE_CREDIT_COSTS[mediaType];

  if (!mediaCosts) {
    throw new Error('invalid mediaType');
  }

  const normalizedScene =
    mediaType === 'music' ? 'text-to-music' : scene;

  if (!normalizedScene) {
    throw new Error('invalid scene');
  }

  const cost = mediaCosts[normalizedScene];

  if (typeof cost !== 'number') {
    throw new Error('invalid scene');
  }

  return cost;
}
```

注意：

- 文件必须是纯 TypeScript。
- 不 import 数据库。
- 不 import env。
- 不 import server-only 模块。
- 可以被 API route 和 client component 同时引用。
- 不要从 `src/config/index.ts` 重新导出，避免 client component 间接 import 配置聚合文件。
- 调用点使用 `@/config/ai/credit-costs` 直接导入。
- 用 `typeof cost !== 'number'` 判断，不用 `if (!cost)`，避免未来 `0 credits` 场景被误判。

## 5. 修改点 1：后端真实扣费

文件：

```text
src/app/api/ai/generate/route.ts
```

当前代码：

```ts
let costCredits = 4;

if (mediaType === AIMediaType.IMAGE) {
  if (scene === 'image-to-image') {
    costCredits = 6;
  } else if (scene === 'text-to-image') {
    costCredits = 4;
  } else {
    throw new Error('invalid scene');
  }
} else if (mediaType === AIMediaType.VIDEO) {
  if (scene === 'text-to-video') {
    costCredits = 6;
  } else if (scene === 'image-to-video') {
    costCredits = 8;
  } else if (scene === 'video-to-video') {
    costCredits = 10;
  } else {
    throw new Error('invalid scene');
  }
} else if (mediaType === AIMediaType.MUSIC) {
  costCredits = 10;
  scene = 'text-to-music';
} else {
  throw new Error('invalid mediaType');
}
```

替换为：

```ts
if (mediaType === AIMediaType.MUSIC) {
  scene = 'text-to-music';
}

const costCredits = getGenerationCreditCost({
  mediaType,
  scene,
  family: requestBody.family,
  model,
});
```

同时新增 import：

```ts
import { getGenerationCreditCost } from '@/config/ai/credit-costs';
```

保持不变：

- 后端仍然是扣费权威。
- 前端不传 `costCredits`。
- `getRemainingCredits(user.id)` 仍然在后端校验余额。
- `createAITask(newAITask)` 仍然负责真实扣积分。
- 失败退款继续复用 `src/shared/models/ai_task.ts` 现有逻辑。

## 6. 修改点 2：图片生成器显示

文件：

```text

```



```ts
const costCredits = useMemo(
  () =>
    getGenerationCreditCost({
      mediaType: AIMediaType.IMAGE,

      family: selectedFamily,
    }),

```

```ts

```

需要删除：

- `costCredits` 的 `useState`
- `promptKey` effect 里的 `setCostCredits(6)`
- 无 `promptKey` 分支里的 `setCostCredits(4)`
- `handleTabChange` 里的 `setCostCredits(4 / 6)`

保留：

- `setActiveTab(...)`
- 余额不足判断
- 页面显示 `credits_cost`
- 提交请求体不传 `costCredits`

原因：


## 8. 行为保持不变

第一版改完后，扣费结果必须和现在完全一致。

| mediaType | scene | credits |
|---|---|---:|
| image | text-to-image | 4 |
| image | image-to-image | 6 |
| video | text-to-video | 6 |
| video | image-to-video | 8 |
| video | video-to-video | 10 |
| music | text-to-music | 10 |

这一步只解决重复硬编码，不顺手改成新定价。

新定价后续再在同一个 helper 里加：

```text
family / model override
↓
scene 默认价
```

## 11. 回滚方案

这个改动可回滚，因为只涉及 1 个新文件和 3 个调用点。

回滚方式：

- 删除 `src/config/ai/credit-costs.ts`
- 恢复 `src/app/api/ai/generate/route.ts` 原来的扣费分支
- 恢复 `src/shared/blocks/generator/image.tsx` 原来的 `costCredits` state
- 恢复 `src/shared/blocks/generator/video.tsx` 原来的 3 个视频 credits 常量

不涉及数据库迁移，不涉及订单，不涉及支付，不涉及积分账本结构。

## 12. 最终结论

要抽，但只抽这个薄 helper。

最终改动范围：

```text
1 个新文件：src/config/ai/credit-costs.ts
3 个调用点：route.ts / image.tsx / video.tsx
0 个数据库改动
0 个支付改动
0 个任务模型改动
```

一句话：

```text
先把“扣费规则单一来源”做好，不顺手重构生成器、模型列表、支付套餐和积分系统。
```
