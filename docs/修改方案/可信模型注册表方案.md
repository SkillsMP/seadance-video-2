## 核心设计：一个文件，四处改动

### 唯一新文件：`src/config/ai/models.ts`

```ts
/**
 * Trusted Model Registry
 *
 * `family` is a stable billing SKU identifier surfaced as a product choice,
 * not a model lineage tag. e.g. `seedance-2-fast-480p-video-input` is a
 * billing tier, not a model family name.
 *
 * Invariant: for the same (mediaType, family, scene), credits MUST be
 * identical across all providers. family is a billing SKU; price is a
 * property of the SKU, not of the provider serving it. This invariant
 * lets candidates fallback skip cost recomputation between attempts.
 */

export interface ModelEntry {
  mediaType: 'image' | 'video' | 'music';
  family: string;
  value: string;              // real provider model id
  label: string;
  provider: string;
  scenes: string[];
  enabled: boolean;
  credits: Record<string, number>;                     // scene → cost
  enforced?: Record<string, Record<string, unknown>>;  // scene → forced options
}
```

`enforced` 按 scene 分组，因为同一 family 下不同 scene 的强制参数可能不同。

`enforced` 放的是"改了会影响成本或偏离定价预期"的字段（如 resolution、duration、generate_audio）。不影响成本的字段（如 aspect_ratio）不放 enforced，由用户自由选择。

### 工具函数

```ts
/** 全维度白名单校验：查不到就拒绝 */
export function findModel(
  mediaType: string, provider: string, family: string, scene: string, model: string
): ModelEntry | undefined {
  return MODELS.find(m =>
    m.enabled && m.mediaType === mediaType && m.provider === provider &&
    m.family === family && m.scenes.includes(scene) && m.value === model
  );
}

/**
 * 开发 / CI 校验。返回 errors 数组，不抛异常。
 * 调用位置：AI service init 处，dev 抛错、prod console.error。
 * 不要写成 import 副作用（避免非 AI 页面被误炸）。
 */
export function validateModels(): string[] {
  const errors: string[] = [];
  const enabledModels = MODELS.filter((m) => m.enabled);

  // 1. 每个 enabled entry 的每个 scene 必须有 credits
  for (const m of enabledModels) {
    for (const scene of m.scenes) {
      if (typeof m.credits[scene] !== 'number') {
        errors.push(`missing credits: ${m.family}/${scene}`);
      }
    }
  }

  // 2. 同一 (mediaType, family, scene) 下 credits 必须一致（SKU 同价）
  const creditsSeen = new Map<string, number>();
  for (const m of enabledModels) {
    for (const scene of m.scenes) {
      const key = `${m.mediaType}/${m.family}/${scene}`;
      const cost = m.credits[scene];
      if (creditsSeen.has(key) && creditsSeen.get(key) !== cost) {
        errors.push(`credits drift: ${key} has ${creditsSeen.get(key)} and ${cost}`);
      } else {
        creditsSeen.set(key, cost);
      }
    }
  }

  // 3. (mediaType, provider, family, scene, value) 不能重复
  const entryKeys = new Set<string>();
  for (const m of enabledModels) {
    for (const scene of m.scenes) {
      const key = `${m.mediaType}/${m.provider}/${m.family}/${scene}/${m.value}`;
      if (entryKeys.has(key)) {
        errors.push(`duplicate model entry: ${key}`);
      }
      entryKeys.add(key);
    }
  }

  // 4. enforced 的 scene 必须属于 scenes
  for (const m of enabledModels) {
    for (const enforcedScene of Object.keys(m.enforced ?? {})) {
      if (!m.scenes.includes(enforcedScene)) {
        errors.push(`enforced scene not in scenes: ${m.family}/${enforcedScene}`);
      }
    }
  }

  return errors;
}
```

## 改动清单

### 改动 1：`src/app/api/ai/generate/route.ts`（约 30-50 行）

核心变化：

```ts
// 公开 image/video 请求必须走 candidates 模式：family、scene、candidates 全部必填，缺一 reject
if (supportCandidatesFallback) {
  if (!family || !scene || !candidates?.length) {
    throw new Error('family, scene and candidates are required for image/video');
  }

  // candidates 前置全量校验
  const entries = candidates.map(candidate => {
    const entry = findModel(mediaType, candidate.provider, family, scene, candidate.model);
    if (!entry) {
      throw new Error(`invalid candidate: ${candidate.provider}/${candidate.model}`);
    }
    return entry;
  });

  // cost 从 matched entry 取，不再走 credit-costs.ts 的二层 lookup
  const costCredits = entries[0]?.credits[scene];
  if (typeof costCredits !== 'number') {
    throw new Error(`invalid credits: ${family}/${scene}`);
  }

  // fallback 循环里按对应 entry 合并 enforced，记录实际执行的 finalOptions
  let finalOptionsForTask = options;
  for (const entry of entries) {
    try {
      const enforced = entry.enforced?.[scene] ?? {};
      const finalOptions = { ...(options ?? {}), ...enforced };
      result = await createProviderTask(entry.provider, entry.value, finalOptions);
      finalOptionsForTask = finalOptions;
      finalProvider = entry.provider;
      finalModel = entry.value;
      break;
    } catch (error) {
      candidateErrors.push(...);
    }
  }

  // 创建 ai_task 时保存实际执行的 finalOptions，不是客户端原始 options
  // options: finalOptionsForTask ? JSON.stringify(finalOptionsForTask) : null
}
```

要点：

- 公开的 image/video generate 请求必须走 candidates 模式；缺 `family`、`scene` 或 `candidates` 为空时直接 reject，不 fallback 到旧逻辑。
- `enforced` 最后写入，客户端无法覆盖（即便客户端传了同名字段也被压掉）。
- `costCredits` 取 `entries[0]`，并在运行时确认是 number；因为 `validateModels` 保证同 SKU 同价，fallback 不需要重算。
- `ai_task.options` 保存合并 enforced 后的 `finalOptionsForTask`，方便排查时看到真实执行参数。
- music 通道（`provider + model` 直传）暂不纳入 `findModel` 强校验，保持原逻辑。
- `credit-costs.ts` 暂时保留给 music 或旧代码引用；image/video 新 candidates 路径不再使用它，确认稳定后可删。

## 升级触发条件（什么时候需要加复杂度）

| 触发条件 | 升级到什么 |
|---|---|
| 出现不影响价格的用户可选项（如 aspect_ratio、output_format） | 加 `defaults` / `allowedOptions` |
| 出现影响价格的规格（如 4K、1080p、长时长、音频） | **新增独立 family / SKU**（如 `seedance-2-fast-4k`），不是加 defaults |
| 同一个 family 内真的出现复杂规格分档 | 再考虑 `specKey` |
| 出现第二个 provider 也有协议变体 | 评估是否需要统一 adapter 抽象 |
| 检测到客户端篡改 enforced 字段 | 加 omit-and-log |
| 注册表超 500 条 | 按 mediaType 拆文件 |

核心规则：**影响价格的规格 = 新 SKU，不影响价格的选项 = defaults。** 不要把 4K 当普通 option，否则会重新打开低价高配的风险。

**当前一个都没触发，所以一个都不做。**
