# 四个平台 Nano Banana / Seedance 2.0 / Veo 3.1 / Seedream 5.0 价格对比（2026 年 4 月 15 日核订版） KIE.ai Replicate.com EvoLink.ai WaveSpeed.ai



说明： 以下价格优先采用各平台当前公开的 pricing 页、模型页、官方说明页。同一平台若存在 总价页、模型页、博客页 三种口径不一致，我会直接注明“当前页面口径不一致”，不再把不同 route 混成一个统一价格。视频价格尤其会受到 时长、分辨率、是否带音频、是否有参考图/视频输入 影响。([WaveSpeedAI][2])

## 1. KIE.ai

计价方式：KIE.ai 采用 credit 制，多个公开页面都显示 1 credit ≈ $0.005；部分模型页还注明高阶充值会有 bonus，因此大额充值后的有效单价可能更低。([kie.ai][3])

* Nano Banana（基础）：约 4 credits / 张 ≈ $0.02 / 张。([kie.ai][4])
* Nano Banana Pro：1K/2K = 18 credits（≈ $0.09）；4K = 24 credits（≈ $0.12）。([kie.ai][5])
* Nano Banana 2：1K = $0.04，2K = $0.06，4K = $0.09。([kie.ai][6])
* Seedance 2.0（视频）：当前 KIE pricing 页可核到

  * 480p，with video input：$0.057 / 秒
  * 480p，no video input：$0.095 / 秒
  * 720p，with video input：$0.125 / 秒
  * 720p，no video input：$0.205 / 秒。
    按 8 秒粗算，分别约 $0.46 / $0.76 / $1.00 / $1.64。([kie.ai][7])
  本项目测试入口先采用 `bytedance/seedance-2-fast` 的 480p with video input 固定 5 秒规格，按 $0.057 / 秒约 $0.285 / 次，对应 `45 credits`。
* Sora 2 标准档 / Lite（视频）：KIE 当前公开页写 Sora 2 = $0.015 / 秒，支持文生视频和图生视频，标准档 10 秒，按 10 秒粗算约 $0.15 / 视频；Pro 720P = $0.045 / 秒，1080P = $0.10-$0.13 / 秒。([kie.ai][31])
  接入注意：如果实际调用 `sora-2-text-to-video` 返回 `This interface is temporarily paused.`，不要自动降级到 Sora 2 Pro，应先确认 KIE 当前可用的 stable model id。
* Veo 3.1（视频）：Lite = 30 credits / 视频（≈ $0.15），Fast = 60 credits（≈ $0.30），Quality = 250 credits（≈ $1.25）。([kie.ai][8])
* Seedream 5.0 Lite（图片）：5.5 credits / 张 ≈ $0.0275 / 张。([kie.ai][9])

特点：如果你的重点是 批量出图，或者想把 Seedream 5.0 / Veo 3.1 的公开成本压到比较低，KIE 现在依然很有优势；但 Seedance 2.0 一定要按 480p/720p + 是否有视频输入 分开写，不能再概括成一个单价。([kie.ai][9])

## 2. Replicate.com

计价方式：Replicate 官方 pricing 页说明，其平台 没有固定积分体系；大多数模型按 运行时间 计费，也有少数模型按 输入/输出 计费。([Replicate][10])

* Nano Banana（基础）：$0.039 / 输出图。([Replicate][11])
* Nano Banana Pro：1K/2K = $0.15 / 输出图。([Replicate][12])
* Nano Banana 2：1K = $0.067 / 张，2K = $0.101 / 张。([Replicate][13])
* Seedance 2.0（视频）：

  * 标准版 720p：$0.29 / 秒
  * Fast 720p：$0.22 / 秒
  * 另外公开页还能核到 480p video_in：$0.13 / 秒。([Replicate][14])
* Veo 3.1（视频）：

  * 标准版 with audio：$0.40 / 秒
  * 标准版 without audio：$0.20 / 秒
  * Veo 3.1 Lite：720p = $0.05 / 秒，1080p = $0.08 / 秒。([Replicate][15])
* Seedream 5.0 Lite（图片）：$0.035 / 输出图。([Replicate][16])

特点：Replicate 依然是 开发者友好、文档清晰、接入方便 的代表，但从当前公开价格看，视频整体明显高于 KIE / WaveSpeed 的常见公开档位。([Replicate][10])

## 3. EvoLink.ai

计价方式：EvoLink 页面通常同时展示 美元价格 + credits。从其 Veo 3.1 和 Seedream 5.0 Lite 页面反推，1 credit 大约在 $0.014–$0.015 左右，因此你原文写 “1 credit ≈ $0.015” 基本合理，但更稳妥的写法还是直接写美元价格。([EvoLink][17])

* Nano Banana（基础）：这里有一处明显冲突。模型页顶部写的是 Beta：$0.02 / 张，但同页 pricing 区块写的是 $0.024 / 张（1.6 credits）。保守起见，正文建议按 pricing 区块的 $0.024 / 张 来写。([EvoLink][18])
* Nano Banana Pro：当前模型页 pricing 区块写的是 1K/2K = $0.125 / 张，4K = $0.224 / 张；另外 reference image = $0.001 / 张，web search = $0.013 / 次。注意：EvoLink 旧博客里还出现过 $0.025–$0.05 的旧说法，但它已经和当前模型页不一致。([EvoLink][19])
* Nano Banana 2：同一个页面里分 `Nano Banana 2` 常规版和 `Nano Banana 2 Beta`，两者价格和稳定性不同，不能合并成一个单价。([EvoLink][20])

  * 常规版 `Nano Banana 2`：页面顶部写 $0.042 - $0.141 / 张；Pricing 表为 0.5K = $0.042 / 张、1K = $0.063 / 张、2K = $0.094 / 张、4K = $0.141 / 张；参考图 $0.0005 / 张，web search $0.013 / 次。页面 FAQ / README 区仍残留 2K = $0.0806、4K = $0.1210 的旧口径，写正文时建议优先按 Pricing 表。
  * `Nano Banana 2 Beta`：页面顶部写 $0.035 - $0.079 / 张；Pricing 表为 1K = $0.035 / 张、2K = $0.053 / 张、4K = $0.079 / 张。Beta 的 web search / image search 为内置且不额外收费，但页面明确提示可能偶发不可用，更适合开发测试，不适合作为生产稳定成本口径。
* Seedance 2.0（视频）：这里同样存在 页面口径不一致。

  * 模型页对比区写的是 From $0.176 / 秒；
  * 但 EvoLink 上周发布的 pricing guide 又写：

    * Standard：480p = $0.071 / 秒，720p = $0.153 / 秒
    * Fast：480p = $0.057 / 秒，720p = $0.124 / 秒
    * 并明确说明 音频不额外收费。
      这类模型你不能再笼统写成单一价格，最好直接注明“EvoLink 当前公开页面存在 route 价差”。([EvoLink][21])
* Veo 3.1 Fast（视频）：

  * 720p/1080p，无音频：$0.085 / 秒
  * 720p/1080p，有音频：$0.127 / 秒
  * 4K，无音频：$0.254 / 秒
  * 4K，有音频：$0.297 / 秒。([EvoLink][17])
* Seedream 5.0 Lite（图片）：$0.032 / 张；若开启 web search，额外 $0.0069 / 次。([EvoLink][22])

特点：EvoLink 现在更像一个 “多模型统一路由平台”，优势在于 接入统一、切模型方便、价格有弹性；但如果你要写公开报价，一定要把 “当前模型页价格” 和 “旧博客对比价格” 分开。([EvoLink][19])

## 4. WaveSpeed.ai

计价方式：WaveSpeed 大多数模型页直接以 USD 展示价格；官方 pricing/docs 页面写明，新账户有 $1 试用额度。([WaveSpeedAI][23])

* Nano Banana（基础）：$0.038 / 张。这就是你刚才指出需要补进去的那条，官方模型页明确显示 “$0.038 per image”。([WaveSpeedAI][1])
* Nano Banana Pro：这里不能再简单写成一个价格。

  * `text-to-image-multi` 路由页面写的是 $0.07 / 张；
  * 但 pricing 页和标准 edit 页写的是 1K/2K = $0.14(优惠价$0.12) / 张，4K = $0.24(优惠价$0.204) / 张。
    所以如果你正文里不写 route，最好不要直接写成 “WaveSpeed Nano Banana Pro = $0.07 / 张”。([WaveSpeedAI][24])
* Nano Banana 2：这里必须区分 Fast route 和标准 route。

  * `text-to-image-fast`：官方博客写 2K = $0.045(优惠价$0.038) / 张，4K = $0.05(优惠价$0.043) / 张；这是当前 WaveSpeed 上最便宜的 Nano Banana 2 route。([WaveSpeedAI][25])
  * `text-to-image` 标准 route：0.5K = $0.045(优惠价$0.038) / 张，1K = $0.07(优惠价$0.060) / 张，2K = $0.105(优惠价$0.089) / 张，4K = $0.14(优惠价$0.12) / 张；web search / image search 另加 $0.014 / 次。([WaveSpeedAI][29])
  * `edit` 标准 route：官方文档列价与标准 text-to-image 相同，即 0.5K = $0.045(优惠价$0.038)，1K = $0.07(优惠价$0.060)，2K = $0.105(优惠价$0.089)，4K = $0.14(优惠价$0.12)。([WaveSpeedAI][30])
* Seedance 2.0（视频）：

  * pricing 页列价 $0.10 / 秒；
  * 官方博客还写 5 秒 480p 起 $0.60，15 秒 1080p 到 $5.40；
  * 另一篇对比文又给出 8 秒 1080p ≈ $0.96 的估算。
    因此你原文里把它概括成 “8 秒约 $0.60–$0.96” 会更接近当前公开资料；若只按 pricing 页线性算，则 8 秒约 $0.80。([WaveSpeedAI][26])
* Veo 3.1（视频）：

  * Veo 3.1 Lite text-to-video：720p = $0.30 / 6 秒，1080p = $0.48 / 6 秒，也就是 $0.05 / 秒 和 $0.08 / 秒；
  * Veo 3.1 Fast text-to-video：每次 $1.2，关闭音频 $0.8；
  * 标准 Veo 3.1 text-to-video 页面则写 video + audio = $0.40 / 秒、video only = $0.20 / 秒，按 8 秒约 $3.2 / $1.6。
    所以如果不写清楚是 Lite / Fast / 标准，很容易把 WaveSpeed 的 Veo 价格写乱。([WaveSpeedAI][27])
* Seedream 5.0 Lite（图片）：

  * text-to-image 页写 $0.035 / 张；
  * edit 页写 $0.035 / 张。
    当前 Seedream 5.0 Lite 在 WaveSpeed 的 text-to-image / edit 口径一致。([WaveSpeedAI][28])

特点：WaveSpeed 的优点依然是价格直观、美元显示、试用门槛低；但它和 EvoLink 一样，同模型不同 route 的价格差异非常大，写稿时一定要把 route 名称带上。([WaveSpeedAI][23])

WaveSpeed.ai 单价不一定最低，尤其标准 route 往往比 KIE 更贵；但它的优势是 route 很细，常见有 fast、multi、edit、标准版等个性化模型，适合按“速度 / 成本 / 多图输入 / 编辑能力”拆开选。

所以 WaveSpeed 更像是“灵活路由平台”：低成本任务走 fast，多参考图或复杂输入走 multi / edit，但正式定价时必须把具体 route 写清楚，否则很容易低估成本。

方便记忆：

先记基准：
基础 Nano = $0.02/张
Pro 图 = $0.09/张
Nano 2 2K = $0.06/张。

再记 Seedance 2：
480p 有参考视频 = $0.06/s 左右

Seedance 2 不要记一堆 credits，直接记成“1 秒视频 ≈ 1 张 Pro 图上下；720p 再往上加”。
设 3 个内部锚点：

拉新锚点：基础 Nano = 便宜图
主销锚点：Nano Banana Pro 2K = 你最常卖的图

这样你看任何新模型，都能快速问自己：

相当于几张免费图？
相当于几张主销图？
相当于几秒主销视频？
它算便宜还是贵
应该放在 5 / 15 / 20 / 35 / 60 哪个积分档
它是拉新模型、主销模型，还是高阶模型

## 一句话结论

如果你要把这篇发出去，建议保留你原来的总体判断，但改成下面这种更稳的表述：

* KIE.ai：依然是当前这四个平台里 综合成本最强 的候选，尤其在 Nano Banana 基础版、Seedream 5.0 Lite、Veo 3.1 固定档 上表现突出。([kie.ai][4])
* WaveSpeed.ai：适合强调 美元直显、上手简单、价格透明，但 Nano Banana Pro、Veo 3.1、Seedream 5.0 都必须写清具体 route。([WaveSpeedAI][23])
* EvoLink.ai：适合强调 统一路由和灵活性，但现在不少模型存在 “当前模型页价格”和“旧博客价格”不一致 的情况，正文里要明说。([EvoLink][19])
* Replicate.com：依然最适合强调 开发者生态和接入体验，但若主题是“纯价格对比”，视频部分通常不会占优。([Replicate][10])
